## Bug found and fixed

σ normalization used the standard deviation of the **current** forward. Decode
steps carry one token, so the per-dimension spread was zero and every dimension
was skipped after the prompt: σ-mode steering was a no-op. Fixed by calibrating
on the first multi-token forward (prefill) and reusing it; regression tests cover
the unit and hook paths (`backend/tests/test_vector_steering.py`).

## Experimental findings

All experiments were run on the real model (RX 7600, bf16, greedy), with
held-out prompts and random/sign controls.

| # | Intervention | Result |
|---|---|---|
| 1 | Single layer, top-8 σ | install 0/6; no cancellation; residual α≥40σ collapses |
| 2 | Multi-layer (L8–22), full vectors | install 0/6; cancel 2/6 with opposite signs |
| 3 | Teacher-forced extraction | install 0/6; cancel 4/6 (+29 %) but controls +25 % → generic |
| 4 | Individual MLP neuron, column-gain normalized | 2/80 beat controls; L16 n=3177 dose-response (+0.010→+0.114); generation 1/4 = control |
| 5 | Group of top-8 neurons | screen +0.139 at the **wrong sign**; generation 0/4 |
| 6 | Format (bullets vs prose) | ladder +1 bullet on one prompt; held-out 0/2 |
| 7 | Late layers L19–22, last prompt token | install 0/6; cancel 2/6 vs controls +31 %; first-token flips 1/6, not toward warm |

**Solid findings**

- The system prompt moves persona strongly and immediately (warm: emoji,
  exclamations, contractions; clinical: terse declaratives).
- The logit lens shows the condition-specific preference is **late-forming**:
  L0–6 agree on the chat-template token, L7–14 are uncommitted (≤0.03), the split
  consolidates from ~L15; the final layer predicts the actual first token
  ("Oh" 0.78 vs "The" 0.81). Mean min-probability of the split from L15: 0.219.
- Mean-difference linear directions at any layer/scale do not install or cancel
  the persona; next-token style mass is not a valid proxy for text-level style
  (the group screen rewarded the wrong sign).
- Format is instruction-bound too.

**Interpretation** (not proven): in LFM3-1.7B the persona behaves like an
instruction-following policy that the model resolves late, not a linear dial.
The lens can *read* the state; reading is not control.

## Closed vs open

**Closed** (with controls): single-layer, multi-layer, late-layer, teacher-forced,
individual-neuron and group-of-neurons mean-difference steering for persona and
for format.

**Open**
1. Probe-learned direction: fit a linear classifier for style, steer its weights.
   A predictive-but-not-causal result would settle "readable vs causal".
2. Attention-head patching with the existing `POST /experiments/patch`
   infrastructure (extend to heads / multiple positions).
3. Local axes where steering may genuinely work: verbosity, list format, refusal
   on benign sensitive prompts, language (ES/EN).
4. Longer-term: SAE features on captured activations.

## Environment notes for the next session

- GPU is hidden by the default sandbox: ROCm needs `/dev/kfd` and `/dev/dri`.
  Run GPU commands with the wider sandbox mode (danger-full-access). Without it
  `torch.cuda.is_available()` is `False`.
- `~/.cache/uv` is read-only here; prefix uv with
  `UV_CACHE_DIR=$PWD/.uv-cache`.
- Model weights are cached; use `HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1`.
- Backend tests: `UV_CACHE_DIR=$PWD/.uv-cache uv run --offline pytest backend/tests -q`
  → **118 passed, 3 skipped**. Frontend: `npm test` → **85 tests, 9 files**;
  `npm run build` passes; `ruff check .` clean.
- Scripts write JSON under `data/pilot/` (gitignored). Plots/screenshots live in
  `docs/screenshots/`.
- The Interpret drawer's patch tab does not expose system fields yet (API does).
